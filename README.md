# 한산 공식 홈페이지 — 간결한 개편판 (v3)

## 변경점
- 메인 배너를 원본 757×426 비율 그대로 표시합니다. `cover` 확대/잘림 없음.
- 중복된 대형 제목, 장식선, 나침반/해도 일러스트, 불필요한 장식을 제거했습니다.
- 메인 배너 아래에 한 줄 소개와 데모 버튼을 배치했습니다.
- 한국어/영어 전환, 반응형 레이아웃, 데모 및 피드백 링크를 유지합니다.
- 스크린샷/영상 파일이 없으면 빈 플레이스홀더를 표시하지 않습니다.

## GitHub Pages 적용
1. 압축 해제 후 저장소 최상위의 `index.html`을 이 파일로 교체합니다.
2. `images/hansan-game-banner.png`를 같은 경로에 업로드합니다. 이미 있다면 확인만 해도 됩니다.
3. 기존 `images` 안의 다른 파일은 삭제하지 않아도 됩니다.
4. Commit changes 후 `https://walexjung.github.io/hansan-official/` 접속, Ctrl+F5 새로고침.
