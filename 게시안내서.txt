〈한산: 난중일기〉 공식 홈페이지 게시 안내서
==========================================

1. 압축을 해제하고 index.html을 더블클릭하면 홈페이지를 미리 볼 수 있습니다.
2. GitHub.com에 로그인하고 새 Public 저장소 hansan-official을 생성합니다.
3. 압축 안의 파일과 images 폴더를 저장소 최상위에 업로드합니다.
4. 저장소 Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. 게시 후 예상 주소: https://walexjung.github.io/hansan-official/
6. 반드시 데모 버튼·언어 전환·모바일·피드백 링크를 점검하세요.

주의사항
- 영화 〈한산〉의 포스터와 스틸컷은 저작권 허가 없이 사용하지 않습니다.
- 본 패키지는 사진 대신 순수 CSS로 만든 바다/배 실루엣 비주얼을 사용합니다.
- images/screenshot-1.jpg와 screenshot-2.jpg에 본인의 게임 스크린샷을 넣으면 자동 표시됩니다.
- 피드백 버튼은 임시로 GitHub Issues 주소에 연결되어 있습니다. 실제 저장소의 Issues 활성화 확인이 필요합니다.
- 현재 스토브 상태는 사용자가 알려준 '심사 중'으로 표기했습니다. 게시 시 재확인하세요.
- 웹 데모 외에 영화·게임 원본 영상 등은 패키지에 포함하지 않았습니다.
