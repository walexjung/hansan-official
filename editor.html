콘텐츠 관리

내 PC에서 게임 이미지와 오프닝 영상을 선택하고 미리보기를 확인한 뒤, 홈페이지용 파일명으로 저장할 수 있습니다.

1. 저장 위치 선택

Chrome·Edge에서는 GitHub에서 관리하는 홈페이지 폴더를 선택해 파일을 직접 저장할 수 있습니다. 다른 브라우저에서는 개별 파일을 다운로드하세요.

폴더를 선택하지 않았습니다.

이 기능은 로컬 파일 저장입니다. GitHub Pages에 공개하려면 저장된 파일을 GitHub 저장소에 Commit해야 합니다. 방문자에게 업로드 권한을 주지 않습니다.

2. 이미지·동영상 선택

3. Google 설문 링크 관리

Google Forms나 Tally에서 '누구나 응답 가능'한 설문을 만든 뒤 공유 주소를 넣으세요. 저장하면 홈페이지의 피드백 제출하기 버튼에 연결됩니다.

현재 Google 설문을 기본으로 사용합니다. GitHub Issues는 별도의 보조 버그 제보 링크로 유지됩니다.

4. GitHub 공개 적용

  • 홈페이지 저장소에서 index.html, editor.html, site-config.js와 images/, video/의 새 파일을 업로드합니다.
  • GitHub 저장소의 Commit changes를 눌러 변경 내용을 공개합니다.
  • 이 관리 화면은 방문자와 서버의 파일을 직접 변경할 권한이 없습니다. 개인 PC의 파일을 편집할 때 사용하세요.

주의: 공개 홈페이지 주소의 /editor.html은 누구나 열 수 있지만, 각자의 PC에서만 저장 동작이 일어납니다. 인증 정보·API 토큰을 이 페이지에 입력하지 마세요.
